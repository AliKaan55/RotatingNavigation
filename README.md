# Rotating Navigation Animation

Bu proje, sayfa açıldığında veya menü butonuna tıklandığında **yan menünün döner animasyonla açılıp kapanmasını** sağlar.  
Kullanıcı hamburger menü ikonuna bastığında içerik alanı döner ve sidebar menü görünür hale gelir.

## 🚀 Özellikler
- Döner animasyonlu navigation menü
- Sidebar içinde HOME, ABOUT, CONTACT linkleri
- Modern ve etkileşimli kullanıcı deneyimi
- HTML, CSS ve JavaScript ile geliştirilmiş

## 🛠️ Kullanılan Teknolojiler
- **HTML5** → Yapı için  
- **CSS3** → Animasyon ve stil için  
- **JavaScript (ES6)** → Menü aç/kapat kontrolü için
